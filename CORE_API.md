# Splinely document/core API (schema version 1)

Crate: `splinely_document`. All model types are public, serde serializable, use camelCase JSON fields; tagged enums use `type` and camelCase variant names. IDs are stable caller-assigned `String`s: ASCII letter/underscore first, then letters/digits/underscore/hyphen/dot. Top-level IDs are globally unique, state IDs unique within each machine, and node ID `splinely-project` is reserved. No editor/runtime dependencies.

## Rust API
- `from_json_strict<T: serde::de::DeserializeOwned + serde::Serialize>(json: &str) -> Result<T, DocumentError>` rejects duplicate members, unknown nested model fields, oversized integer tokens and typed numerical loss; missing/default fields are permitted. Arbitrary `serde_json::Value` payload keys remain valid. Used by project loading and native runtime wire requests.
- `Project::default()`; fields: `schema_version: u32`, `name: String`, `width/height: f64`, `nodes: Vec<Node>`, `bones: Vec<Bone>` (default empty), `clips: Vec<Clip>`, `state_machines: Vec<StateMachine>`, `variables: BTreeMap<String, serde_json::Value>`, `audio_assets: Vec<AudioAsset>`, `audio_cues: Vec<AudioCue>`, `speech_cues: Vec<SpeechCue>`, `custom_js: String`, `raw_svg: String`.
- `Project::validate() -> Result<(), DocumentError>`; `to_json()`, `from_json(&str)` validate; `to_svg(&self, runtime: &str) -> Result<String, DocumentError>` embeds JSON in `<metadata id="splinely-project">`, caller-supplied runtime in script, and renders time zero. `to_static_svg(time: f64)` renders without runtime. Raw SVG is preserved as data, **not injected** into export. Custom JS is preserved in JSON and is never executed by the core loader or bare runtime. `to_svg_with_options(&self, runtime: &str, options: BrowserExportOptions) -> Result<String, DocumentError>` adds an explicit host bootstrap: `{ trusted_js, speech, audio_controls }`; audio controls add user-gesture unlock, trusted JS runs only with opt-in.
- `Project::evaluate(time: f64) -> Result<Vec<Node>, DocumentError>`: immutable evaluation, active autoplay clips in document priority order (later override clips win), linear/step/cubic-bezier easing. `evaluate_clip(clip_id: &str, time: f64)` selects just that clip over base + initial-state overrides; seconds are local clip time. `evaluate_with_context(time, &EvaluationContext)` supplies `states: BTreeMap<String,String>`, `clips: Option<Vec<ClipPlayback>>`, `clip_weights: BTreeMap<String,f64>` (default empty), and `overrides: Vec<PropertyOverride>`. `ClipPlayback { clip_id,time }` is local clip time; `None` selects autoplay, `Some([])` selects no clips. Precedence: base → states (machine order) → clips (list/document order) → explicit overrides. Loop boundaries wrap to zero; nonloops hold final values; before first key, first value is held. Times must be finite and nonnegative.
- `Bone { id: String, parent_id: Option<String>, x: f64, y: f64, rotation: f64, length: f64 }` (`parentId` defaults to null). Root x/y are scene coordinates; child x/y are offsets from the parent tip rotated by the parent world angle. Child rotation is relative, in degrees. Length must be positive and finite. IDs share the global project namespace. Missing parents/attachments, cycles, depth >128, nonfinite numbers and pose/attachment overflow are rejected.
- `Project::evaluate_bones(&self, time: f64, context: &EvaluationContext) -> Result<Vec<BonePose>, DocumentError>` returns poses in bone vector order using the same state → clip → explicit override precedence as node evaluation. `BonePose { id: String, x: f64, y: f64, rotation: f64, length: f64 }` is the world-space root and angle; tip is `(x + length*cos(rotation), y + length*sin(rotation))` (angle converted to radians). Tracks, overrides and SetProperty actions may target bone IDs, but only numeric x/y/rotation are supported. Actions remain host-managed.
- Node evaluation returns **already attached** transforms: local translation is rotated by the bone world angle and added to its root, node rotation adds that angle, scales and local geometry remain unchanged. Do not apply binding again to evaluated nodes. Source nodes/bones remain immutable. Export uses these posed nodes; bones are guides, not visible SVG geometry. Interactive SVG metadata retains original local nodes and bones.
- `Node { id, name, bone_id: Option<String>, visible: bool, locked: bool, original_kind: Option<Box<NodeKind>>, transform: Transform, style: Style, kind: NodeKind }`. Additive schema-v1 JSON defaults: `boneId: null`, `visible: true`, `locked: false`, `originalKind: null`. Nodes render in vector order (later nodes on top); invisible nodes are omitted from SVG geometry, but preserved in metadata. No layer schema: layer UI reorders nodes, toggles visibility, and honors locked (an editor flag, not an evaluation/export restriction).
- `Node::convert_to_path(&mut self) -> Result<(), DocumentError>` converts only finite rect/circle geometry with positive dimensions/radius, preserving ID, style, transform, binding and flags. Rect corners use exact SVG elliptical arcs with SVG rx clamping; circles use exact circular arcs. Local `NodeKind::Path { d: String, bounds: [f64;4], evenodd: bool }` stores `[x,y,width,height]` selection bounds. Generated paths must meet the existing importer path safety limits. Conversion saves the explicit rect/circle in `originalKind`. Text needs font outlines and is rejected; existing paths are rejected.
- `Node::convert_back(&mut self) -> Result<(), DocumentError>` restores the saved rect/circle only if the current path equals the deterministic generated path exactly (d, bounds and evenodd); modified/imported paths are rejected without mutation. Style/transform changes do not prevent restoration. Success clears originalKind. Saved geometry is validated, must be rect/circle, and may exist only on path nodes; modified paths remain valid documents but cannot restore until exactly matching again.
- `Node::rect(id, x, y, width, height)`, `Node::circle(id, cx, cy, radius)`, `Node::text(id, x, y, text)` convenience constructors. Geometry is tagged `kind: {type:"rect",x,y,width,height,rx}`, `{type:"circle",cx,cy,radius}`, `{type:"text",x,y,text,fontSize}`.
- `Transform { x,y,rotation,scale_x,scale_y }` defaults to identity. `Style { fill: Color, stroke: Option<Color>, stroke_width, opacity }`. `Color { r,g,b,a }` uses f64 channels 0..1; `Color::rgb(r,g,b)` takes u8 channels. Colors export as RGB + separate alpha.
- `Clip { id,name,duration,looping,autoplay,blend_mode: BlendMode,weight: f64,tracks: Vec<Track> }`; `BlendMode::{Override,Weighted}` serializes as `override` / `weighted`. Missing JSON `blendMode` defaults to Override and `weight` to 1; schema version remains 1. Authored and context weights must be finite in [0,1], including inactive clips; context keys must reference existing clips. Context weights replace authored weights without mutating or activating clips. Override mode ignores weight and preserves legacy replacement behavior exactly.
- Contiguous weighted clips in the selected priority sequence form a group; every override clip (even with no tracks) flushes it. For each target/property, B is the value before the group, S is the sum of weights of clips with that track, and D=max(1,S): `B*max(0,1-S) + sum(sample_i*weight_i/D)`. Missing channels do not contribute to S. Zero weights preserve the baseline, including absent stroke; positive stroke contributions use transparent RGBA if the baseline stroke is absent. Numbers (including scalar rotation) and sRGB RGBA channels blend independently; local bone channels blend before FK/attachment. State overrides precede groups and explicit overrides follow them. No shortest-angle rotation or world-pose blending.
- `Track { node_id, property: Property, keyframes: Vec<Keyframe> }`; `Keyframe { time, value: AnimValue, easing: Easing }`. Keyframe easing controls the interval starting at that keyframe. `AnimValue` is `{type:"number",value: f64}` or `{type:"color",value: Color}`. `Property` serialized names: x,y,rotation,scaleX,scaleY,opacity,fill,stroke,width,height,radius,fontSize. x/y animate transform translation (not geometry position). `Easing`: `{type:"linear"}`, `{type:"step"}`, `{type:"cubicBezier",x1,y1,x2,y2}`.
- `StateMachine { id,initial,states: Vec<State>,transitions: Vec<Transition> }`; `State { id,on_enter: Vec<Action>,overrides: Vec<PropertyOverride> }`; `Transition { from,to,event: Event,guard: Option<Guard>,actions: Vec<Action> }`; first matching transition wins. `Event { name,target: Option<String> }`; authored ordinary event targets reference nodes; `clip.end` targets reference a clip or reserved global `@timeline`. `Guard { variable,equals: serde_json::Value }`. `Action` variants: SetProperty {node_id,property,value}, PlayClip {clip_id}, StopClip {clip_id}, BlendClip {clip_id: String,weight: f64,duration: f64}, SetVariable {name,value}, Emit {event}, PlayAudio {asset_id}, Speak {text,lang}. `MachineInstance::new(project,machine_id) -> Result<MachineInstance,DocumentError>` initializes `machine_id`, `current_state`, `variables`, and `initial_actions` (host should perform these once). `send(project,event) -> Result<Vec<Action>,DocumentError>` returns transition actions followed by destination on-enter actions. SetVariable actions update instance variables internally; all other actions are host-managed. BlendClip serializes as `{"type":"blendClip","clipId":"...","weight":0.5,"duration":0.2}`; omitted duration defaults to 0. It requires an existing Weighted clip, finite weight in [0,1], and finite nonnegative duration (no upper bound). It requests a host-managed fade only: it never implicitly activates, restarts, or stops a clip. Core returns the action unchanged; native preview and browser hosts must implement it explicitly. Two independent machines are parallel states, not weighted blending themselves. Emitted events are not recursively dispatched. Untargeted transitions match any target. Instances have independent variable snapshots; host coordinates shared variables across machines.
- `AudioAsset { id,name,mime_type,data_base64 }` (canonical RFC 4648 base64 only, no external URL; MIME must be audio/subtype without parameters). `AudioCue { id,asset_id,time,offset,duration: Option<f64>,volume }`; `SpeechCue { id,time,text,lang,rate,pitch,volume }`. Audio/speech times are global transport seconds.
- `Command`: AddNode(Node), RemoveNode {id}, ReplaceNode(Node), ReplaceProject(Project). `History::default()`; `execute(&mut self, &mut Project, Command) -> Result<(), DocumentError>`; `undo/redo(&mut self,&mut Project) -> bool`; `can_undo/can_redo`. Commands validate before committing; full project snapshots preserve all fields. `execute_batch(project, commands)` creates a single atomic undo transaction; only the final snapshot must validate. Removing referenced nodes fails rather than silently deleting tracks/behavior; replace the project to remove references in the same transaction. `clear()` resets history. Direct document edits invalidate history.

## Runtime/export contract
Root SVG has `data-splinely-version="1"`; metadata textContent is parseable JSON; nodes are SVG elements with original IDs and `data-splinely-node` attributes. Runtime script is CDATA wrapped (embedded `]]>` is split safely). Runtime should discover its owning SVG through `document.currentScript.ownerSVGElement`, read `#splinely-project` within that SVG, and not depend on global IDs. Metadata XML escaping is decoded by DOM textContent. Script initialization is runtime's responsibility. Embedded assets remain base64 JSON strings. No include_str requirement in the core: editor may supply `include_str!("../../../runtime/src/splinely.js")` to `to_svg`.

## Scope and limitations
Schema 1 only; unknown versions rejected (no historical migration yet). Rect/circle/text/path nodes only, no group/layer schema. `Project::from_svg(source: &str) -> Result<Project, DocumentError>` supports bounded, all-or-nothing safe vector import into paths, retaining original SVG as data. Unsupported appearance/resources/scripts/text/images are rejected rather than silently flattened. Raw SVG is never executed or injected into export. Rust evaluation does not execute JS, audio, or state side effects; state actions are returned for host processing. Weighted clip blending is additive schema-v1 support as frozen in `BLENDING_SPEC.md`; it is not delta/additive-pose blending. Core is stateless: hosts synchronize fades into `EvaluationContext.clip_weights`; fade clocks, interruption/paused behavior, and audio scheduling are host responsibilities. Variables are scalar JSON values (null/bool/number/string); guards and assignments must match declared types. Cubic-bezier control coordinates are restricted to 0..1 (no overshoot); colors interpolate componentwise sRGB, not perceptually. XML-forbidden characters in rendered text/title or runtime source fail export; raw/source strings in JSON remain preserved. Runtime embedding is intended for XML SVG, not arbitrary HTML string injection. No asset size quotas, atomic disk-save/autosave, geometry hit-testing, or historical migrations yet. Browser script permissions, audio unlocking, speech/offline availability, and untrusted code isolation remain host responsibilities.
